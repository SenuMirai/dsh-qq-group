# 接话触发器设计（v3：价值评分）

> 2026-10-21。替换 v2 的「概率 + 闸门」，改为可解释的 0~100 分。

## 为什么改

旧版：
- 每条消息掷一次概率 → 一波话里反复掷，行为抖动；
- 只区分关键词/成员/闲聊，没法表达「同一个人接着说，但已经转去跟别人聊了」；
- 白/黑名单只能靠概率表，不能强制上下限。

## 流程

```
群消息
  → @ / 叫名字 / 引用回复她 → 100% 直接回（不进评分）
  → 其他消息：6 秒去抖窗口攒一波
  → 算一次价值分 0~100
  → 分数 ≥ 阈值：按 分数/100 掷一次
  → 命中：LLM 闸门读最近 16 条，判断「在跟她说 / 在跟别人说」
  → 说她 → 生成回复；说别人 → 静默
```

## 评分表

| 分项 | 分值 |
|---|---|
| 基础 | +30 |
| 关键词命中 | +概率 × 50（如 DeepSeek 0.85 → +43） |
| 指定成员 | +概率 × 50 |
| 刚跟她聊过的人接着说 | +30 |
| 话里带「你 / 您 / 妳」 | +15 |
| 熟识度 | +0 ~ +8（按 0~100 折算） |
| 好感度 | -10 ~ +10（按 -100~100 折算） |
| @ 了别人 | -30 |
| 被冷落（连续主动没人接） | -8 / 次（最多 4 次） |
| 夜间免打扰命中 | -20 |
| 一波只有一条消息 | -5 |
| 白名单 | 分数至少 = 下限（默认 95） |
| 黑名单 | 分数最多 = 上限（默认 5） |

- 阈值 `scoreThreshold` 默认 50（按群可调）；
- **真正概率 = 分数 / 100**：80 分 ≈ 80%，和「按 80% 概率搭话」一致；
- 分数、每一项理由都写日志：`接话判定：接/不接（…评分 76/50…）`。

## 闸门（v2 保留）

- 只对 `ambient` / `engaged` 生效；@、叫名字、引用回复不经过闸门；
- 读最近 16 条 + 这一波 + 当前人的熟识度/好感度；
- 提示词明确要求判断「是跟她说，还是跟别人说」，同一个人接着说也可能已经转话题；
- 超时 15 秒 / 失败 → 回退到启发式结果。

## 白名单 / 黑名单

- 设置页一行一个 QQ；
- 白名单：固定评分下限 `whitelistFloor`（默认 95）；
- 黑名单：固定评分上限 `blacklistCeil`（默认 5）；
- 只影响主动接话评分，**不影响别人 @ 她必须回**。

## 熟识度 / 好感度

- 每个群、每个人一份（`profiles.json`）；
- 熟识度：发言 +0.5、每天首次 +3、被点名 +1.5、她回复 +1（0~100）；
- 好感度：她每回复一次 +1（-100~100）；
- 只用于评分和回复语气，负好感也不冷落、不阴阳；
- 回复提示词里会注入「你对 TA 的印象」，但不让模型念数字。

## 夜间免打扰

- 默认 23:00–08:00，可配置起止小时，支持跨午夜；
- 命中时评分 -20（不是完全禁言，避免错过真正点她名的话）。

## 后续（v4）

- 价值评分学习：根据「她说完有没有人接」反向调整关键词/成员权重；
- 对话双方追踪（引用链、连续对话）；
- 上下文摘要（长群聊压缩成一段群记忆，而不仅是截断）。
