# 记忆架构

## 1. 三层短期记忆

### 短期上下文

- 每个群保存原始聊天轮次，默认上限 200 条 / 12000 tokens。
- 回复时只取最近 N 条：
  - 默认 24 条；
  - 短句自适应默认 4 条；
  - 1.24.4 起实际至少 32 条 / 8 条，并额外保留最近 60 条中的关键旧消息。
- 超过上下文但还没压缩的原文仍在文件里，只是不进入提示词。

### 摘要 + 关键记忆

- 只有原始轮次超过 `memoryMaxTurns` 或 `memoryMaxTokens` 时才触发压缩。
- 压缩时模型产出：
  - `summary`：摘要，默认最多 2000 字；
  - `keyMemories`：关键记忆，默认最多 50 条。
- 关键记忆不按时间自动衰减，但受 50 条上限限制。
- 摘要会截断旧内容。

### memory-v3

- 基础半衰期 30 天，情绪半衰期 7 天。
- 淡忘只影响召回排序，不自动删除条目。
- 自动写入有每日聊天配额（默认 8 条）。

## 2. 永久记忆（双层）

独立文件：`permanent-memory.json`。

### 全局层（global）

只存主人相关内容：

```text
主人的称呼、偏好、禁忌
主人的约定、重要日期
主人和她的共同经历
```

读取规则：

```text
主人私聊：读取全局 + 当前会话
主人在群里说话：读取全局（仅 normal）+ 当前群
主人不在群里：不读取全局
其他人私聊：不读取主人全局
```

私密标记：

- `sensitivity=private` 的全局记忆只在主人私聊读取；
- 绝不进入任何群聊；
- 手动添加全局记忆时可勾选“私密”。

### 会话层（session）

每个群/私聊独立：

```text
这个群的梗
这个群的重要的人
这段私聊的约定
```

不跨群，不读取其他会话的内容。

### 自动记录

- 主人在私聊说的话 → 全局层，默认标记为私密；
- 主人在群里说的话 → 当前群的会话层；
- 自定义 QQ 名单里的人 → 当前会话层；
- 同一人 10 分钟内连续消息合并成一条。

### 容量

```text
会话层：默认 200 条/会话
全局层：默认 100 条
```

满了只封存，不自动删除；旧记忆保留，自动记录暂停，UI 提示容量不足。

### 手动管理

- 新增：可选本会话 / 全局；全局可标记私密；
- 删除单条；
- 多选 AI 合并（同层内）；
- 会话条目可手动“提升”到全局；
- 全局容量满了会阻止提升。

### 注入

每次按相关度/新近度选最多：

```text
12 条 / 1500 字
```

全局和会话合并后选取；私密全局在群聊会被过滤。

## 3. 为什么她会“没聊几句就忘”

1. 群消息密度高，24 条可能只覆盖几分钟。
2. 短句走自适应 4 条，关键消息容易被挤出。
3. 24 条只是提示词窗口，不是摘要触发线。
4. 摘要只记大概，容易丢掉 URL、数字、具体约定。
5. 关键记忆只在压缩时产生。

## 4. 边界

- 永久记忆不是无限数据库；容量满后必须人工清理。
- 全局层只建议存主人相关；群友隐私不要提升到全局。
- 自动记录从启用后开始，旧聊天不会自动补。
- 机器人回复不会自动写回永久记忆；需要保存的结论请手动添加。
- 跨群不共享会话层；全局私密内容不会进群。
